RepShare: Recipe Sharing Website

A website for sharing recipes. Users can create, view, edit, and delete recipes. The site allows users to browse a list of recipes, view detailed instructions, and manage their recipes.

recipeRoutes.js
Contains CRUD functionality: create, read, update, and delete recipes. 

Style using Bootstrap along with a custom CSS file

Views:
    partials                // partials used by other views
        header.ejs              // header
        footer.ejs              // footer
    home.ejs                // homepage
    create-recipe.ejs       // recipe creation form page
    all-recipe.ejs          // view all recipes page

Backend using:
Node.js
Express.js
MongoDB
Mongoose

Deployed on:
Render: cloud hosting app
MongoDB Atlas: cloud database
